ผู้ใช้งาน · Who uses it

BestOS ใช้งานโดยเจ้าของเพียงคนเดียว และเข้าถึงเฉพาะบัญชี Google ของเจ้าของ ไม่มีผู้ใช้อื่น

BestOS is used by its owner only and connects only to the owner's own Google account. There are no other users.

ข้อมูลที่เข้าถึง · Data accessed

  • Gmail: อ่านอีเมลและสร้างฉบับร่าง ไม่ส่ง ไม่ลบ · read messages and create drafts; no sending or deleting
  • Google Calendar: อ่านและสร้างหรือแก้นัดหมาย · read, create and edit events
  • Google Drive, Docs, Sheets: ค้นหา อ่าน สร้าง และแก้ไฟล์ ไม่ลบ ไม่แชร์ · search, read, create and edit files; no deleting or sharing

การใช้และการเก็บข้อมูล · Use and storage

ข้อมูลใช้เพื่อให้ผู้ช่วย AI ของเจ้าของทำงานตามที่เจ้าของสั่งเท่านั้น กุญแจเข้าถึงเก็บบนเครื่องเซิร์ฟเวอร์ของเจ้าของ ไม่ขาย ไม่แบ่งปัน และไม่ส่งต่อให้บุคคลที่สาม ไม่ใช้เพื่อโฆษณา

Data is used only so the owner's AI assistants can carry out the owner's own requests. Access tokens are stored on the owner's server. Data is never sold, shared or transferred to third parties, and is not used for advertising.

BestOS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

การยกเลิกสิทธิ์ · Revoking access

เจ้าของยกเลิกสิทธิ์ได้ทุกเมื่อที่ myaccount.google.com/permissions

The owner can revoke access at any time at myaccount.google.com/permissions.
